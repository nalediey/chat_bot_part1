this is the running code and it includes:
The project which is a C# console chatbot that helps users learn about cybersecurity.
It asks the user to enter their name and checks if the name is valid.
The chatbot stores cybersecurity topics and answers using a dictionary.
It removes unnecessary words from the user’s question to understand it better.
The program reads the user’s question and looks for matching keywords.
If a match is found, it gives the correct answer to the user.
If the input is wrong or empty, it shows an error message.
The user can type words like exit or bye to close the program.
The chatbot uses colours and typing effects to make it more interactive.
This project shows basic use of loops, conditions, and collections in C#.
